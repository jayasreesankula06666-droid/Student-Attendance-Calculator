# Student Attendance Calculator

A responsive beginner-friendly web project that calculates attendance percentage and checks it against a required attendance target.

## Features

- Calculates attendance percentage automatically
- Lets the user set the required attendance percentage (defaults to 75%)
- Shows whether the student meets the requirement
- Estimates how many consecutive future classes are needed to reach the target
- Validates incorrect inputs
- Responsive layout for desktop and mobile
- Built with plain HTML, CSS, and JavaScript; no installation required

## Project files

- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — calculation and validation logic

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter total classes held, classes attended, and the required percentage.
4. Click **Calculate attendance**.

## Formula

**Attendance percentage** = (Classes attended ÷ Total classes held) × 100

Example: If a student attended 45 out of 60 classes:

(45 ÷ 60) × 100 = **75%**

## Publish with GitHub Pages

1. Upload all project files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under the build/deployment section, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the website.
